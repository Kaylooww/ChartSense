Apply the setups of the user-supplied guides

visual-v0.3 (D-028, from S10)
- Falling wedge breakout added as a bullish reversal (only after the
  breakout and once lower lows have stopped)
- Latest-move question: a break counts only when a candle CLOSES beyond the
  level, not a brief wick (answers on all four test strips unchanged)
- Not added: overextended filter. The model called the uptrend strip
  overextended but its exact mirror (downtrend) not, so the filter would
  block UP and pass DOWN (biased). Higher-timeframe trend, volume, stop-loss
  and 2:1 reward also left out (not visible / not fixed-expiry)

Signal rule (introduced as visual-v0.2, D-026)
- UP/DOWN when a completed setup fits its context and no opposing setup is
  visible, on two consecutive snapshots: pullback resumed (needs the trend),
  range breakout/breakdown and triangle/flag/cup-and-handle breakouts (need
  the trend or a range), double bottom/top and (inverse) head and shoulders
  (need the opposing structure to have stopped). Bullish + bearish -> WAIT
  (SIGNAL_CONFLICT); trend without a completed setup -> WAIT
  (NO_CONFIRMED_SETUP). Evidence cites the guide rule used. Moving-average
  rules not used (cannot be measured from pixels)

Model requests (D-026, D-027)
- Structure is a required single choice (higher highs/lows, lower highs/lows,
  range, unclear); named chart patterns stay an optional list with one-line
  definitions; explicit criteria for image quality and trend; ignore
  watermarks and overlays
- Each snapshot now asks two questions: the whole crop (quality, trend,
  structure, named patterns), then a zoomed strip of the newest 30% of the
  candles asking one required choice: broke above recent highs, broke below
  recent lows, pulled back then turned up, bounced then turned down, none.
  Both answers must be valid
- downscaleToBase64 can keep only the right part of the crop (fromX)
- Request code refactored into one validated chat() helper

Why: on qwen3-vl:4b-instruct the optional pattern list stayed empty even on
a clean uptrend, so every result was WAIT; asking the latest move on the
whole chart made the model echo the overall trend. With the forced choices
and the zoomed strip, four test crops now give: new highs -> UP, new lows ->
DOWN, bottom turning up in a downtrend -> WAIT, dip in an uptrend that
turned up -> UP (pullback), each in a few seconds.
