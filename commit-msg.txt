feat(training): T1 dataset and baseline; real-crop import, AI drafts and review

Start the model training track (D-029) with dataset creation and baseline
evaluation. No model is trained and the extension's analysis is unchanged.

Extension
- ollama.ts: export PROMPT, MOVE_PROMPT, LatestMoveSchema and a shared
  patternsFrom() so training data uses exactly what the extension sends
  (behaviour unchanged)
- Opt-in training export in the "show screenshot" section: Prepare export
  of this crop -> review both model images -> privacy checkbox -> Save
  training file link. The file holds the two images, capture time,
  timeframe and a session id only (strict schema, no URL/site/account data);
  nothing is stored or uploaded. The prepared export is a frozen snapshot
  and stays mounted, so live monitoring does not reset a review (bug found
  and fixed while testing in Chrome)

training/ workspace (Node runs TypeScript directly, no new dependencies)
- lib/labels: labels derived from both structured-output schemas; example
  folder format (chart.png, recent.png, example.json)
- lib/synth + lib/png: deterministic synthetic charts with labels by
  construction (8 scenarios; down scenarios mirror up ones to expose bias),
  dependency-free PNG encoder, same 30% newest-candles strip
- lib/split: chronological, group-aware 70/15/15 split (no session in two
  splits; test newer than train)
- lib/metrics: field accuracy, per-pattern precision/recall, invalid JSON
  rate, latency mean/p50/p95, visual-v0.3 decision agreement vs gold
- lib/backtest: walk-forward rule test with no look-ahead, non-overlapping
  trades; lib/sft: chat-format SFT records from train/validation only
- scripts: synth, import, validate, split, evaluate (real observeChart;
  incomplete runs flagged), backtest (CSV or no-edge random walk),
  prepare-sft; npm run training:* scripts; typecheck + tests in npm run check
- Docs: training/README.md, finetune/README.md (QLoRA plan, NOT tested),
  reports/BASELINE.md; DECISIONS D-029, roadmap training track,
  PROJECT_CONTEXT, README; .gitignore for training data and exports

Real supplied crops (D-030, start of T2)
- training:import-crops imports the 330-crop ExpertOption set (11 screenshots,
  8 instruments) into data/real as source "user_crop", images prepared like
  the extension (1024 px crop + newest 30% strip), labels always null (the
  set's older LABEL_SCHEMA is never copied); group = instrument so
  overlapping crops and same-session screenshots never cross splits
- training:review: local labeling page (127.0.0.1:5210) showing both model
  images and the allowed values; every save validated by LabelsSchema
- lib/png: dependency-free PNG decoder and area-average downscale (+ test)
- training:split --source real|synthetic (splits-<source>.json, real and
  synthetic never mixed); training:eval --splits <file>, report records it
- README: dataset limits and missing market conditions; DECISIONS D-030;
  roadmap T2 in progress. No labels added, no model trained

AI draft labeling and review workflow (D-031)
- Review page: Auto-Label All with the local Ollama model (default
  qwen3-vl:2b-instruct, editable), through the extension's real observeChart;
  progress, cancel, 0-5 retries, missing model stops the run, each crop saved
  immediately so a rerun resumes with unlabeled + failed crops only
- Answers stored as example.json "draft" (labels, timeframe label, notes,
  warnings, model, time, sha256 of both images); never written to labels
- reviewStatus unlabeled/draft/approved/rejected/failed; schema enforces
  labels set exactly when approved; Approve / Reject with note / Clear;
  status filter with counts; model text HTML-escaped on the page
- Line charts: candlesVisible forced false in drafts (flagged) and refused
  on approval
- Export Verified Dataset: approved real crops + images, labels.jsonl and
  manifest with a chronological group-aware split (groups never cross),
  draft model and whether the reviewer changed the draft
- lib/annotate.mts (+ 9 tests: drafts, line charts, retries, resume,
  cancel, model missing, concurrent review, approval rules, export);
  page moved to scripts/review-page.mts; .gitignore data/exports and
  splits-*.json
- training:validate counted only user_export as real; now counts every
  non-synthetic example (user_crop showed as 0 real)

- qwen3-vl:2b-instruct, 24 synthetic test charts: 0% invalid JSON,
  latestMove 41.7%, structure 75%, rule decision agreement 50%, strong
  upward bias, p95 8.3 s per image
- baseline-v0.1 on a 3,000-bar no-edge random walk: 52.4% on 103 trades
  (consistent with no edge and no look-ahead)
- qwen3-vl:2b-instruct on the real test split (30 USD/BRL crops): 100% on
  every field, but the gold labels are its own drafts approved unchanged,
  so this is self-agreement, not accuracy (reports/BASELINE.md); latency
  mean 2.6 s, p95 2.9 s per image
