feat(monitor): add live chart monitoring with local Ollama vision (visual-v0.1)

Make live website analysis the primary input instead of OHLC file uploads.
Everything stays free and local: the cropped chart goes only to Ollama on
127.0.0.1. Simulation only; no orders, no site interaction.

- Add Ollama client (analysis/ollama.ts): connection check, /api/chat with a
  JSON-schema response, Zod validation, fixed visual-pattern vocabulary,
  hides model notes containing numbers, timeout and cancel
- Add visual-v0.1 rule (signals/visual.ts): UP/DOWN only when trend,
  structure and a visible breakout agree on two consecutive snapshots of the
  same region; otherwise WAIT, or INSUFFICIENT_DATA for unreadable charts,
  model failures, missing context; WAIT for snapshots stale vs the horizon.
  No prices, indicators or confidence derived from pixels
- Add monitoring loop (hooks/useMonitor.ts): capture -> crop -> downscale ->
  model -> rule, one cycle at a time at a configurable 5-60 s interval; waits
  for region selection; restarts and hides old results on input change;
  ends on Pause, Stop, tab loss or closing the panel
- Add Monitor UI: chart-context form, model and interval selects, Ollama
  status and setup steps, last analysis / next capture, detected patterns and
  the structured result card; rename Start capture to Start monitoring
- Move the OHLC file import to a Developer tab as a testing tool; extract a
  shared ChartContextForm
- Lock extension network access: CSP connect-src only
  http://127.0.0.1:11434; security tests assert the exact CSP and that no
  other URL appears in src/
- Make captureOnce awaitable; update risk notice, error copy and source hints
- Docs: DECISIONS D-020..D-022, PROJECT_CONTEXT decision update, roadmap
  (Phase 3 done, monitoring done early, journal next), README setup and
  verification notes

Verified: npm run check (161 tests); Chrome 156 automated run with a
stand-in Ollama (WAIT then UP, crop-only upload, INSUFFICIENT_DATA when
Ollama stops, Stop ends the loop) and against real Ollama 0.40.15 without
OLLAMA_ORIGINS (shows Not reachable + INSUFFICIENT_DATA). Not verified: a
real qwen3-vl:4b answer, its latency/VRAM, or use on a real trading site.
